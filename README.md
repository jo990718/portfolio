# WON 절세 시나리오 | AI 챗봇

최종관 · 금융 IT · 검토용 초안

## 소개

최종관 | 금융 IT에 관심을 두고 사용자 의사와 계산 결과를 연결하는 서비스를 고민합니다.

## 프로젝트

WON 절세 시나리오 | 우리 AX 해커톤 | 2026.10.26 - 2026.10.28 | 4인 팀 | 구현된 시연용 프로토타입

해외주식 투자자가 손실 중인 주식의 매도를 망설이거나 절세 선택지를 이해하기 어려운 상황을 다뤘습니다. 사용자의 보유 의사를 반영한 시나리오와 예상 세금, 근거를 함께 보여줍니다.

## 나의 기여

OpenAI Responses API를 연동하고 챗봇의 역할과 응답 지침을 설계했습니다. 사용자 발화에서 매도 제외·최대 매도 비율 등의 조건을 추출하고, 모호한 의도는 확인 질문을 하도록 응답 과정을 정리했습니다.

조건을 대화에서 분리해 적용 예정 상태로 관리하고 화면에 표시한 뒤, 사용자가 시나리오 보기를 선택하도록 흐름을 구성했습니다. 기사·공시 원문을 확인할 수 있도록 근거 연결에도 참여했습니다.

팀 결과물에는 React 화면, Spring Boot API, Java 계산 엔진과 기업 자료 검색이 포함됩니다. 위 개인 기여는 작성자 진술이며 화면·계산 엔진의 전체 구현을 개인 성과로 주장하지 않습니다.

## 구현 흐름

React가 사용자 메시지, 선택 종목, 기존 조건과 대화 ID를 백엔드에 전송합니다. Spring Boot는 최근 대화와 조건 등을 OpenAI에 전달하고, 모델이 반환한 JSON 조건을 검증합니다.

화면은 적용 예정 조건과 확인 질문을 보여줍니다. 사용자가 시나리오 보기를 선택하면 Java가 조건에 따른 세액을 계산합니다. AI 전략 제안의 수량도 서버 측 조건 검증과 계산을 거칩니다.

관련 코드: frontend/src/App.jsx, backend/src/main/java/com/woori/tax/AssistantService.java, OpenAiService.java 및 LiveAssessmentService.java

## 직접 확인한 시연

입력: “인텔은 팔고싶지 않고 최대 절세 혜택을 받고 싶어” → 인텔 매도 제외 조건을 추출하고 시나리오를 비교했습니다. 영상에서 보유 유지 예상 세금 594,000원과 한 시나리오의 예상 세금 0원을 확인했습니다.

입력: “가진 손실을 다양하게 매도하면서 절세 안을 만들어줘” → 조건을 확인하고 새로운 시나리오와 보고서를 살펴봤습니다. 작성자가 기록한 보고서 수치는 예상 세금 594,000원 → 0원, 3개 종목 42주 매도, 매도 후 현금 5,592,222원입니다.

시연 영상에서 세금과 현금 수치는 확인했으나 3개 종목 42주는 별도 확인이 필요합니다. 현재 실행에서 재현 검증은 하지 않았으며 AI 생성 제목과 결과는 실행 시점 및 입력에 따라 달라질 수 있습니다.

## 문제와 배운 점

조건이 바뀌는 대화에서 이전 맥락이 꼬이거나 특정 종목이 반복 제안되는 어려움이 있었습니다. 작성자는 추출 조건을 별도 상태로 관리하고 재시뮬레이션에 전달하는 구조가 중요하다는 점을 배웠습니다.

금융 AI에서는 자연스러운 설명뿐 아니라 계산 결과의 검증과 근거 확인이 중요하다는 점을 배웠습니다. 출처 링크는 원문 확인을 돕지만 AI 요약의 정확성 자체를 보장하지는 않습니다.

## 기술과 현재 한계

React·Vite: 대화 화면과 조건 표시 / Java·Spring Boot: API, 검증과 계산 / OpenAI Responses API: 자연어 조건 추출과 웹 검색. 기술 목록은 팀 프로젝트 전체 기준입니다.

시연용 가상 계좌와 가정에 기반하며 실제 계좌 연결이나 주문 기능은 없습니다. 대화 상태는 서버 메모리에 있어 재시작 시 초기화됩니다.
