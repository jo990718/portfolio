# 최종관 | 포트폴리오

안녕하세요. 금융 서비스에서 사용자가 필요한 정보를 쉽게 이해하고 자신의 상황에 맞는 선택을 할 수 있도록 돕는 개발자가 되고 싶은 최종관입니다.

AX 해커톤에서 해외주식 절세 시나리오 서비스의 AI 챗봇을 개발하며, 사용자의 투자 의사를 대화로 정리하고 시나리오 비교에 반영하는 경험을 했습니다.

## 기술 사용 경험

- **OpenAI Responses API · Java · Spring Boot:** AX 해커톤에서 챗봇의 API 연동, 응답 지침과 백엔드 응답 검증 로직을 구현했습니다. 사용자의 발화를 매도 조건으로 정리하는 흐름을 다뤘습니다.
- **React · Vite:** 팀 프로젝트의 대화 화면과 조건 표시 화면에 사용된 기술입니다. 해당 프론트엔드 화면은 제가 담당한 작업이 아닙니다.

## 프로젝트

### WON 절세 시나리오 | AI 챗봇

- **기간:** 2026.10.26–2026.10.28 · 4인 팀
- **프로젝트:** 해외주식 투자자의 보유 의사를 반영해 절세 시나리오와 예상 세금을 비교하는 시연용 서비스
- **나의 역할:** OpenAI API 연동, 챗봇 응답 지침 설계, 투자 의사 조건 추출 및 백엔드 응답 검증 로직 구현
- **기술:** React, Vite, Java, Spring Boot, OpenAI Responses API (팀 프로젝트 기준)
